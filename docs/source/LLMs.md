# Teach Your LLM to Use Maverick

```{note}
This page is about teaching LLMs to use Maverick. If you are interested in creating LLM-based players, take a look at this example: {doc}`LLM as Player <examples/llm_as_player>`.
```

Maverick provides LLM-friendly documentation to help AI tools like Cursor, Windsurf, GitHub Copilot, ChatGPT, and Claude understand and work with the library.

There are two main ways to teach an LLM to use Maverick:

1) Download the llms-full.txt file and paste it into your LLM's context window.
2) Point your LLM to the llms.txt file and let them explore the necessary parts of the library, based on your query. This would make the LLM to always use the most actual current documentation rather than stale training data.
