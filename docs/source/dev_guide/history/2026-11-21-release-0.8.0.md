# Release 0.8.0 and an updated Claude Code skill

| | |
|---|---|
| **Date** | 2026-11-21 |
| **PR / Issues** | #114 |
| **Version** | 0.8.0 |
| **Breaking** | No |

## Summary

Version 0.7.0 was released from the state of `dev` before saving games (#111) and
seeding isolated players (#112) were merged, but the changelog never got a `[0.7.0]`
section and both features were documented as added in 0.7.0. This change bumps the
version to 0.8.0, splits the changelog into a `[0.7.0]` and a `[0.8.0]` section, and
corrects the `versionadded` and `versionchanged` directives of the features that ship in
0.8.0. It also brings the `maverick` skill of the Claude Code plugin up to date with
player isolation, player state export and import, seeding, and saving, replaying and
resuming games, and bumps the plugin to 1.1.0.

## Details

### Changes

- `pyproject.toml` and `uv.lock`: version 0.8.0.
- `CHANGELOG.md`: the entries after the `v0.7.0` tag (saving, loading and replaying
  games, `GAME_RESUMED`, `Game.save_dir`, `SaveFormatError`, seeded isolated players,
  reading `PokerRules` back from JSON, and the note on keeping saves secret) moved to
  `[0.8.0] - 2026.11.21`. The rest became `[0.7.0] - 2026.11.20`, the date of the tag.
- Docstrings: everything in `maverick.savegame` and `maverick.replay`,
  `GameEventType.GAME_RESUMED`, the `save_dir` argument and property of `Game`,
  `Game.load` and the `versionchanged` note of `Game.start` now say 0.8.0. The `seed`
  argument of `Game` stays `versionadded:: 0.7.0` and got a `versionchanged:: 0.8.0`
  note for the seeding of isolated players.
- `maverick-plugin/skills/maverick.md`:
  - The game setup section lists the `seed`, `player_isolation`, `decision_timeout` and
    `save_dir` arguments, and the context manager. Reproducibility now says to use
    `Game(seed=...)` instead of seeding `random` after creating the game, which no
    longer affects the cards.
  - The player contract mentions `export_state` and `import_state`, fixed UIDs for
    resumable games, and how to write bots that also work under isolation.
  - `GAME_RESUMED` is listed with the event types.
  - New sections on player isolation (configuration, failures, requirements, state
    hooks, seeding of workers, limits) and on saving, replaying and resuming games.
  - The snippets of the new sections were run against this version.
- `maverick-plugin/README.md`: the description of the `maverick` skill.
- `maverick-plugin/.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`:
  plugin version 1.1.0.

### Follow-ups and known limitations

- The history entries {doc}`2026-11-20-save-games` and
  {doc}`2026-11-21-seed-isolated-players` list their version as "0.7.0 (unreleased)".
  The features shipped in 0.8.0. The entries are left as they are, because history
  entries are not edited after they are merged.
