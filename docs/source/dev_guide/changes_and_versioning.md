# Changes and Versioning

The project adheres to [semantic versioning](https://semver.org/).

The changelog is maintained in `CHANGELOG.md` and follows the format specified by [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

The changelog is a high-level overview for users. The details of each change (motivation, design decisions, performance, testing) are recorded in the {doc}`development history <history/index>`, which gets a new entry with every pull request.
